# Local Movers Marketplace

An end-to-end marketplace platform connecting residential moving customers with verified local packers and movers.

## Project Structure

```
├── backend/          # Express.js + TypeScript + MongoDB Modular REST API
├── nextjsfrontend/   # Next.js Web App (Vendor Portal, Admin Portal, Public Website)
├── Reactnative/      # React Native Mobile App (Customer & Worker Experience)
└── documents/        # Product Specifications, Data Models, UX & Delivery Plans
```

## Getting Started

### 1. Backend API (`backend/`)
```bash
cd backend
npm install
npm run dev
```

### 2. Next.js Web Frontend (`nextjsfrontend/`)
```bash
cd nextjsfrontend
npm install
npm run dev
```

### 3. React Native Mobile App (`Reactnative/`)
```bash
cd Reactnative
npm install
npx expo start
```
